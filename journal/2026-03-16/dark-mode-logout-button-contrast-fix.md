# 다크 모드 로그아웃 버튼 가독성 수정

## 변경 내용
- 다크 모드에서 `로그아웃` 버튼 배경이 흰색인데 텍스트도 흰색으로 보이던 문제를 수정했습니다.
- `src/app/index.tsx`에서 로그아웃 버튼 텍스트에 전용 스타일(`secondaryButtonText`)을 적용해 텍스트 색상을 `#111111`로 고정했습니다.

## 검증
- `TAG_NAME=0.0.0 npm run lint` 실행하여 정적 검사 통과를 확인했습니다.

## 참고 / 다음 작업자 메모
- 로그인 세션이 있을 때만 로그아웃 버튼이 렌더링되므로, UI 수동 확인 시 인증 세션이 필요합니다.
- 브라우저 자동 스크린샷 시도는 타임아웃으로 실패했습니다(환경/연결 이슈 가능).
