# Scroll collapse jitter fix

## 요청
- TODO 목록을 스크롤하다가 상태 카드가 접힐 때 스크롤 위치 변화와 함께 화면이 "부들부들" 떨리는 현상 수정.

## 변경 사항
- `src/app/index.tsx`의 접힘 토글 로직을 단일 임계값 기반(`> 20` 즉시 토글)에서 히스테리시스 형태로 개선.
- 접힘은 `y > 20`일 때만 발생하도록 유지.
- 다시 펼침은 스크롤이 맨 위(`y <= 0`)로 돌아왔을 때만 발생하도록 제한.
- 결과적으로 접힘 직후 레이아웃 변화로 인한 미세한 `y` 변동이 즉시 역토글을 유발하지 않게 되어 흔들림 현상을 완화.
