# Widget/App 목록 일치화 작업

## 요청
- 앱 내 TODO 목록과 Android 홈 위젯 목록이 다르게 보여서 동일하게 맞춰달라는 요청.

## 원인
- 위젯 렌더러(`WidgetRoot`)에서 `snapshot.todos.slice(0, 4)`로 목록을 강제로 4개만 노출하고 있었음.
- 앱 화면은 캐시/동기화 결과 전체 목록을 보여주므로 표시 개수가 달라 불일치가 발생.

## 변경 사항
- 위젯 목록 제한 제거: `snapshot?.todos ?? []` 사용.
- 완료 상태 가시성 강화: 완료된 항목은 `(완료됨)` 라벨과 회색 톤으로 표시.

## 검증
- `npm run lint` 통과.
- `npx tsc --noEmit` 통과.

## 참고
- Android 홈 위젯 변경이라 브라우저 기반 스크린샷으로 실제 위젯 화면을 캡처하기 어려움.
