# Simplify sync status and remove header card

## 요청 배경
- 기존 헤더 축소 이후에도 상단 표현을 더 단순화하고, 동기화 상태 메시지를 더 간결하게 만들자는 피드백 반영.
- 특히 헤더를 카드 형태가 아닌 기본 배경 위 텍스트 영역으로 보이도록 조정 요청.

## 변경 내용
- 헤더 래퍼를 `ThemedView(type=backgroundElement)` 카드에서 일반 `View` 기반 `headerSection`으로 변경.
- 헤더 스타일에서 카드 느낌 요소(rounded card)를 제거하고, 상단은 배경 위에 바로 노출되는 가벼운 spacing만 유지.
- 상태 배지 텍스트를 기술값(`SUCCESS` 등) 대신 사용자 친화 라벨(`동기화 완료`, `동기화 중`)로 통일.
- 동기화 상태 문구를 간결화:
  - `동기화 준비 중 (인증 토큰 확인 완료)` → `준비 중`
  - `OneDrive 연결 중...` → `연결 중`
  - 상세 진행 메시지는 `목록 확인 중`, `N/M 파일 처리` 형태로 축약
  - 복구/오류 상태 문구도 `캐시 표시 중`, `캐시로 복구됨`으로 단순화
- 상태 카드 제목을 `연결 상태`에서 `동기화 상태`로 변경해 의미를 명확히 함.

## 검증
- `npm run lint` 통과
- `npx tsc --noEmit` 통과
- `TAG_NAME=0.0.0 npm run web -- --port 8081` 실행 후 수동 화면 확인 및 스크린샷 캡처
- 실행 로그에서 RN DevTools의 시스템 라이브러리 누락(`libatk-1.0.so.0`)은 계속 노출되지만, 웹 번들링/화면 검증은 정상 완료
