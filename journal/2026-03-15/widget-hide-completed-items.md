# 위젯 완료 항목 비표시 조정

## 배경
- 이전 수정으로 위젯이 스냅샷 전체 목록을 보여주도록 바꿨지만, 위젯 공간 제약 때문에 데이터가 많을 때 가독성이 떨어지는 피드백이 발생.

## 변경
- Android 홈 위젯 렌더링에서 `completed=true` 항목을 필터링하여 미완료 TODO만 노출.
- 완료 라벨 `(완료됨)` 및 완료 항목 색상 분기 제거.
- 필터링 결과가 비어 있을 때 안내 문구를 `표시할 미완료 항목이 없습니다.`로 변경.

## 검증
- `npm run lint`
- `npx tsc --noEmit`
