# 상태 카드 collapse 지터 근본 원인 대응: 방향/시간 의존 제거

## 문제 재정의
- 기존 로직은 스크롤 방향(delta)과 시간 쿨다운에 의존해 진동을 완화했지만, 레이아웃 변화 직후 발생하는 오프셋 점프 자체를 구조적으로 분리하지 못했다.
- 사용자 관점에서 이는 "덜 보이게 숨긴 보정"처럼 느껴질 수 있다.

## 근본 대응
- collapse 상태 전환 기준을 **순수 offset 기반 상태기계**로 단순화했다.
  - 진입: `y >= 36`
  - 복귀: `y <= 2` (사실상 리스트 최상단)
- 방향(delta) 판정, 토글 타임스탬프, 쿨다운 가드를 제거했다.
- `onScroll`/`onScrollEnd` 모두 같은 `syncCollapseStateForOffset` 경로를 사용하도록 정리했다.

## 기대 효과
- 레이아웃 애니메이션 중간 이벤트 순서/타이밍에 덜 민감해져, 상태 전환이 예측 가능해진다.
- 중간 구간(예: 2~36px)에서 오프셋이 흔들려도 상태가 재토글되지 않아 진동 가능성을 낮춘다.
