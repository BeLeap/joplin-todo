# 상태 카드 collapse 임계 구간 확대

## 배경
- offset 기반 상태기계로 단순화한 뒤에도 일부 스크롤 패턴에서 collapse 시 시각적 떨림이 남는 피드백이 있었다.
- 사용자 요청대로 임계 구간 자체를 더 넓혀, 경계 근처에서 전환이 발생할 가능성을 더 낮추기로 했다.

## 변경
- collapse 진입 임계값을 `36 -> 72`로 상향.
- expand 복귀 임계값을 `2 -> 0`으로 조정.
  - 즉, 상단 완전 복귀 시점에서만 확장되도록 고정.

## 의도
- 카드 접힘은 충분히 아래로 스크롤된 뒤에만 발생시키고,
- 펼침은 리스트가 최상단으로 완전히 돌아왔을 때만 허용해 경계 근처 왕복 전환을 더 강하게 차단.
