# 위젯 TODO 목록 전체 노출로 변경

## 배경
- 위젯 리스트가 스크롤 가능함에도 불구하고 일부 항목만 미리보기로 잘라 보여주고 있어, 실제 미완료 TODO 전체를 빠르게 확인하기 어렵다는 피드백이 있었다.

## 수행 내용
- 위젯 렌더링에서 `previewTodos`(상위 n개 slice) 로직을 제거하고, 미완료 TODO 전체를 `ListWidget`에 렌더링하도록 변경.
- 마지막 행의 `marginBottom` 계산을 전체 리스트 기준으로 조정.
- `+N개 더 있음` 안내 배지를 제거해, 스크롤 리스트 자체가 전체 목록을 직접 표현하도록 단순화.
- 위젯 스냅샷 기본 최대 항목 수를 제한 없는 값(`Number.MAX_SAFE_INTEGER`)으로 상향.
- 위젯 게시 시 고정 상한(100개) 대신 현재 TODO 길이(`todos.length`)를 전달하여 스냅샷에도 전체 목록이 저장되도록 변경.

## 기대 효과
- 위젯에서 미완료 TODO 전체를 스크롤로 확인 가능.
- 앱/위젯 간 표시 데이터 불일치(일부만 표시) 완화.
- 목록 요약 배지 제거로 UI/로직 단순화.
